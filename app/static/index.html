KV cache map

what each slot is holding right now
Releasing a slot does not throw its work away. On builds with unified KV and idle-slot caching, an idle slot’s state is parked in llama.cpp’s host-RAM prompt cache (--cache-ram) and restored when a request with the same prefix arrives, so an idle slot reading 0 is normal. What does lose it is eviction from that cache, or a state too big for it — both counted under Request health above.
